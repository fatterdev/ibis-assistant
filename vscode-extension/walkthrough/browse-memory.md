The activity-bar **Ibis Assistant** view lists memory kinds (decision, fix, rule, …) with entries from MCP `memory_list`; click an entry for the full detail. Kind browse and search show only still-valid memories — the title-bar filter button (or **Ibis Assistant: Toggle Memory Status Filter**) widens the browse to every status for curation.

Open the view, then attach the **ibis-session-contract** chat instruction to agent sessions so they call `load_session_context` once and keep memory hygiene.
